# Third-party software in release builds

Release builds include the programs and libraries below, unchanged. Lite packages leave out FFmpeg and MKVToolNix. Each keeps its own licence. Source code is available from the links.

| Component | Included in | Licence | Source |
|---|---|---|---|
| FFmpeg (ffmpeg, ffprobe), builds by BtbN | Windows full | GPL-3.0 | https://github.com/BtbN/FFmpeg-Builds, https://ffmpeg.org |
| FFmpeg (ffmpeg, ffprobe), builds by Martin Riedl | macOS full | GPL-3.0 | https://ffmpeg.martin-riedl.de, https://ffmpeg.org |
| MKVToolNix (mkvmerge, mkvextract) | Windows full | GPL-2.0 | https://mkvtoolnix.download/source.html |
| Python | all | PSF-2.0 | https://www.python.org |
| Tcl/Tk | all | Tcl/Tk licence (BSD-style) | https://www.tcl-lang.org |
| Pillow | all | MIT-CMU | https://github.com/python-pillow/Pillow |
| OpenCV (opencv-python-headless) | all | Apache-2.0 | https://github.com/opencv/opencv-python |
| NumPy | all | BSD-3-Clause | https://numpy.org |

MakeMKV is not included. Install it from https://www.makemkv.com. libdvdcss is not included either; see the README.
